#+TITLE: mw-thesaurus.el changelog
#+AUTHOR: Ag Ibragimov

Changes to the project, following Keep a Changelog conventions.

* [Unreleased]

** Added
- ~mw-thesaurus-dictionary-lookup-dwim~ looks up the region, the word at point or a word it asks for in the Merriam-Webster Collegiate Dictionary, with a shared key in ~mw-thesaurus-dictionary-api-key~; the idea and its first implementation come from Marty Hiatt's fork, [[https://codeberg.org/martianh/mw.el][mw.el]]
- a dictionary page shows the word split into syllables, its pronunciations and inflections, its senses as an Org list with examples and usage notes, and the word's history
- a pronunciation with a recording plays it: a button with a speaker on a graphic display, an Org link in a terminal; ~mw-thesaurus-audio-player~ names the player, by default the first of afplay, mpv, ffplay and mpg123 found
- on a thesaurus page, an entry the dictionary also has gets a speaker after its heading; its first press asks the dictionary for the recording
- the faces ~mw-thesaurus-syllables~, ~mw-thesaurus-pronunciation~ and ~mw-thesaurus-example~, gray by default
- the header line names both references and marks the one shown; ~o~, or a click on the other label, shows the word in the other reference, and ~l~ goes back across both
- ~RET~ on a dictionary page looks up the word at point in the dictionary
- ~C-c C-o~, or ~M-x mw-thesaurus-browse~, opens the page shown on merriam-webster.com

** Changed
- ~C-c C-o~ no longer looks up the word at point, which ~RET~ does; on a pronunciation it still plays it
- a refused API key also says which variable to set
- ~RET~, ~l~ and ~q~ in the thesaurus buffer, and evil's ~RET~, ~H~ and ~q~, act only while the page is read-only, as it is after every lookup; after ~C-x C-q~ the page types them and evil's keys work as in any buffer
- these keys live in the new ~mw-thesaurus-read-only-map~, which outranks ~mw-thesaurus-mode-map~; a single-key binding of your own, such as the readme's Doom remaps, goes there too
- ~l~ brings back a page as it first showed; edits made to it after ~C-x C-q~ do not come back

** Fixed
- with ~org-indent-mode~ on, a page is no longer indented twice: it leaves the indentation of its body to ~org-indent-mode~

* [1.4.0] - 2026-11-02

** Added
- ~l~ in the thesaurus buffer, ~H~ with evil, goes back to the previous lookup and to where point was, without a new request

* [1.3.0] - 2026-11-02

** Changed
- ~mw-thesaurus-mode~ is a major mode derived from Org mode, not a minor mode on top of it: keys bound in ~mw-thesaurus-mode-map~, also with ~evil-define-key~, override Org's; ~mw-thesaurus-mode-hook~ still runs

** Fixed
- the thesaurus buffer hides the emphasis markers around italic words; the setting meant to hide them had no effect

* [1.2.1] - 2026-11-01

** Fixed
- a word with no entry, such as "both", says so; it showed the entries of phrases with the word, such as "burn" for "burn the candle at both ends"
- a word's entries no longer include entries that only list a phrase with it: "neither" no longer shows "fish"
- with evil, ~q~ quits the thesaurus buffer and ~RET~ looks up the word at point; evil's normal state took both keys
- a spelling suggestion also has to differ in no more than half of the word, so "I" no longer shows "GI"

* [1.2.0] - 2026-11-01

** Changed
- lookups use Merriam-Webster's v3 JSON API, the data the website shows: "tenacity" and "mice" have entries, and "weakest" shows "weak"
- a misspelled word falls back to its first spelling suggestion only when the two differ by one or two letters, so "etymology" no longer shows "genealogy"
- v3 also lists compound entries: "happy" shows "happy-go-lucky" and "trigger-happy" too
- the lists under each heading line up again
- an answer that arrives while a prompt is open no longer takes the focus from it
- requires Emacs 27.1

** Fixed
- phrases of three or more words, such as "break the law" and "under the weather"
- a selection that ends with a space or spans a line break
- ~RET~ in the thesaurus buffer looks up the word at point, as the readme says
- a failed request or a bad API key says so in the echo area; a bad key showed "No Merriam-Webster entry"

** Removed
- the ~request~ and ~dash~ dependencies

* [1.1.0] - 2026-09-26

** Added
- a misspelled word shows the entry of its first spelling suggestion, and the echo area names both words

** Changed
- the API key variable is ~mw-thesaurus-api-key~; it was ~mw-thesaurus--api-key~
- requires Emacs 26.1

** Fixed
- a selection with a space, such as "give up", is URL-encoded
- a ~wrong-type-argument keymapp nil~ error
- a lookup no longer turns on ~org-hide-emphasis-markers~ in every buffer

* [1.0.1] - 2021-02-23

** Added
- ~mw-thesaurus-lookup-dwim~ looks up the selection, the word at point, or a word it asks for
- ~mw-thesaurus-lookup~ looks up the selection
- ~C-c C-o~ in the thesaurus buffer looks up the word at point
- ~q~ quits the thesaurus buffer and its window
- autoloads for the commands

** Fixed
- every entry shows, not only the first
- the thesaurus buffer opens when it already exists
- carriage returns in the thesaurus buffer

** Removed
- the dependency on ~s~
- the evil-specific ~q~ binding

* [0.0.1] - 2017-09-03

** Added
- looks up a word at dictionaryapi.com and shows its meanings, examples, synonyms, related words, near antonyms and antonyms as an Org outline
